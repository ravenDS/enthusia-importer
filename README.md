# Enthusia Importer
A Blender plugin to import **Enthusia Professional Racing (PS2)** car models & map models (.pkd)

**Compatibility**: Blender 4.2+

## Usage
- Install the plugin by dragging the plugin .zip into Blender window
- Extract contents of the game with [Enthusia Extract](https://github.com/ravenDS/enthusia-extract/)
- Import any `.pkd` file in Blender from `/pack/carpk/` (cars) or `/pack/mappk/` (maps)
- Enjoy!

## Notes
- `/pack/carpk/` contains the in-race car models, `/pack/selcarpk/` contains the car models from the selection screen
- This project is AI-assisted (disassembly work)
